EXPORT DE TRANSPORT DES 1200 RESULTATS BASELINES

Tous les JSON retenus sont copies octet pour octet, avec leurs champs et sceaux originaux. Les 1200 identites sont controlees; ce transfert ne refait pas l'audit numerique des energies. Les journaux par run, sorties terminales, anciens plans repetes, caches, environnements et archives historiques ne sont pas copies. Ils restent intacts sur la machine. Le journal global du superviseur est conserve pour les changements de ressources.

Les volumes ZIP sont des archives independantes, pas des fragments a concatener. Extraire tous les volumes dans le meme dossier pour retrouver les chemins relatifs.
MANIFEST.json indexe les fichiers; SHA256SUMS.txt controle les archives.
