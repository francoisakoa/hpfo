# Licensing and publication review

or establish rights over third-party material. The author must reconcile this
package with the repository's existing license before public distribution.

Compiled libraries, virtual environments and optional HSL binaries are not
intended for this source release. Dependencies should be installed separately.
Check the exclusion manifest: an excluded required fixture or nested source
archive must be addressed before claiming complete reproducibility.

identities, private correspondence or unrelated project material.
