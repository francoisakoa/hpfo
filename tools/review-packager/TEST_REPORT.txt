OBSERVED DEFECT
The user's diagnostic identifies valid JSON records with method, n_atoms,
run_id, energy, wall_time and n_func_evals. The R1 parser accepted the other
fields but did not recognize n_func_evals, so its result-shaped-record filter
returned None. With a complete synthetic 1200-record grid using those field
names, the original unmodified R1 kit reproduces found=0 and missing=1200.
No numerical values from the user's real baselines were invented for this test.
